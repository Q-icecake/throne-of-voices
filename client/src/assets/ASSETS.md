# 임시 SVG 자산

2026-10-25 UI 중간 검토를 위해 프로젝트 안에서 직접 작성한 벡터다. 외부 이미지·폰트 다운로드나 CK3 화면의 복사/삽입을 사용하지 않았다. 역사 고증을 마친 최종 미술 자산이 아니다.

| 자산 키 | 파일 | 용도 |
|---|---|---|
| court.background | court-background.svg | 원근 건축·바닥·후경 자리·조명 |
| court.foreground | court-foreground.svg | 양쪽 전경 책상·문서·먹 |
| character.zhangHong | zhang-hong.svg | 장굉 임시 인물·접지 그림자 |
| map.jiangdong | jiangdong-map.svg | 기존 M0의 형주·장강·강동 개념도 재구성 |

자산 키는 통합본의 `../scene/assets.ts`에서 관리한다. 문서 본문·인물 이름·입력·버튼은 DOM을 사용한다. 지도 글자는 개념도의 지명이며 관측된 군사 정보가 아니다. 새 자산으로 교체할 때 화면 승인, 용량/출처 기록, 두 해상도 재검토가 필요하다.

## 002 통합 · 2단계
- 출처: B `<Codex 원본 루트>/client/src/assets/`의 직접 작성 임시 SVG와 본 기록. 궁정 배경·전경·장굉 파일은 원본 그대로 복사했다.
- 궁정 1600×900은 A의 1920×1080 슬롯에 동일 비율로 표시한다. 손권과 호위는 A의 코드 SVG를 유지하고 손권만 새 좌석에 맞춘다.
- 장굉은 별도 `character.zhangHong` 슬롯(220×400)을 사용한다. 얼굴·소매·발과 바닥 그림자를 포함하며 이름표와 클릭 영역은 DOM이다.
- 궁정 이미지 실패 시 A SVG와 기존 소품 위치로 복귀한다. 장굉 이미지 실패 시 A 인물 SVG를 유지한다. 실패가 입력·명령·자료 접근을 막지 않는다.
- 외부/유료 자산, 새 패키지, 참고 이미지의 번들 포함은 없다. 역사 고증을 마친 최종 미술이 아니다.

## 002 통합 · 3단계
- `jiangdong-map.svg`: B의 종이 그라데이션·격자·장강·산 표현을 사용한다. A의 `map-jiangdong`/`map-navy` ID와 키보드·보고 연결을 위한 표식 영역을 추가했다. `../ui/panels.ts`에서 정적 SVG로 가져오며 기존 공개 문서만 연결한다.
- 문서: B `client/src/style.css`의 종이 그라데이션을 `../panels.css`의 `.paper`에 한정해 적용하고 아주 옅은 CSS 섬유선을 추가했다. 별도 이미지나 폰트는 없다. A의 장부 합성·출처·관측 시각·관련 작업·보고 링크는 유지했다.
- 본문은 문서 17px, 명령·지도 설명·입력 16px 이상. 지도는 시험용 개념도이며 실제 축척이나 숨은 군사 정보가 아니다.
# M4 추가 인물 임시 변형

`zhang-zhao.svg`, `zhou-yu.svg`, `lu-su.svg`는 이 저장소의 `zhang-hong.svg`에서 색·관·소품을 조금 바꾼 접견/회의용 임시 표현이다. 외부 자산을 가져오지 않았으며 최종 인물 아트가 아니다. 장조는 관 장식, 주유는 청색 포인트와 칼집, 노숙은 황토색 포인트와 문서 소품으로 구분한다.
