# 적벽 전야의 배경 메모 — 사료 미대조 초안

범위: 208년 적벽 전야를 소재로 한 게임의 콘텐츠 검토 자료. 인터넷·외부 API·실물 사료를 조회하지 않았다. 아래에서 ‘널리 인정’은 검토 우선순위를 정하기 위한 잠정 분류이며, 이번 작업에서 검증했다는 뜻이 아니다. 실제 서신의 인용문이나 번역문은 포함하지 않는다.

## 검증 체크리스트 — 위험도가 높은 다섯 묶음

- [ ] **연도·사건 관계 (A01, A02, B03):** 208년 표기, 형주 정세 변화, 유비 이동, 손권 측 논의의 앞뒤 관계를 대조한다. 게임 개시점을 달력상의 특정 하루로 단정하지 않는다.
- [ ] **호칭·관직·위치 (A03, B05, C01):** 손권을 후대 왕호로 부르지 않는지, 장굉·장조·주유·노숙의 당시 관직과 소재가 맞는지 확인한다. 네 인물의 즉시 접견과 정무청은 재구성 표시를 유지한다.
- [ ] **병력·지리·실제 전투력 (B01, B03):** 자료의 수량 집계 범위, 지명 대응, 관측·전달 지연을 확인한다. 검증 전에는 정밀 지도 핀과 정확한 실시간 적 병력을 추가하지 않는다.
- [ ] **서신·교섭의 전승 (B02, C03):** 조조 측 서신의 전승·귀속·문구·시점을 확인한다. 본 초안의 한국어 문장이 사료의 직접 인용처럼 소개되지 않는지 확인한다.
- [ ] **인물 논리·내면·미래 결과 (B04, C04, C05):** 장조의 타협론을 비겁함으로, 주유를 승리 보장자로, 노숙을 정답 제시자로 만들지 않았는지 검토한다. 실제 발언·작가의 견해·시험 결과를 분리한다.

검토 후보는 『삼국지』 관련 인물전과 주석, 필요하면 후대 편찬 기록 및 연구 문헌이다. 이번에는 어느 판본·권차·문장도 확인하지 않았으며, 이 이름들은 근거 인용이 아닌 **사람이 찾을 자료 후보**다. 검토자는 판본·권차·쪽/항목·확인 문구·상충 자료·검토일을 별도 기록한 뒤 근거 수준을 갱신해야 한다.
