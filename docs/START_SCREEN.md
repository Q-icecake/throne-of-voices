# 첫 화면과 Gemini 연결 (027)

일반 진입은 첫 화면이다. `Mock으로 시작`은 키·모델·시험 없이 즉시 기존 궁정으로 들어간다. 설정/안내를 읽는 동안 오프닝은 준비되지 않아 시간이 흐르지 않는다. 새 화면은 기존 궁정 SVG와 색상·시스템 글꼴만 사용한다. 기존 궁정·문서·지도·명령·접견 UI는 그대로다.

## 화면 흐름

- 첫 화면: 제목, 소개, Mock 시작 / AI 연결 설정 / 플레이 안내, 연결 상태.
- 설정: Gemini만 표시. 새 서버에서 `GEMINI_MODEL_ID`를 설정하지 않았다면 모델 ID 입력은 비어 있다. `offline-model`은 시험 코드에서만 넣는 값이다. 환경변수 모델 또는 같은 서버 세션에 사용자가 저장한 모델은 표시한다(`키 지우기`는 모델을 지우지 않는다). 모델 ID는 사용자가 콘솔에서 확인한다. 키는 비밀번호 입력이며 표시 토글이 없고 붙여넣기가 가능하다.
- 설정 적용은 호출하지 않는다. `연결 시험`을 눌렀을 때만 `Reply with exactly OK.`를 1회 전송한다. 출력 상한은 8토큰, 재시도는 0회, 총 제한시간은 15초다. 결과는 정상 / 키 오류 / 모델 없음 / 한도 초과 / 시간 초과 / 응답 형식 오류 / 서버 오류로 표시한다. 원문 응답·예외·헤더는 표시하지 않는다.
- `AI로 시작`은 키·모델이 있어야 활성화된다. 시험 전에는 버튼 바로 위에 `시험하지 않았습니다` 확인 문구를 항상 표시하고 진행할 수 있다. 별도 팝업은 없다. 성공 시험도 이후의 접근 권한·가격·무료 한도를 보장하지 않는다.
- 안내는 질문·문서·접견·회의·명령 초안/확인·시험 도구와 여섯 입력 예시를 설명한다. 15분 뒤에도 게임은 계속된다.
- Tab / Shift+Tab / Enter로 조작한다. 페이지 전환 시 제목에 초점을 옮기며 Esc는 첫 화면으로 돌아간다.

## 키와 예산

화면 입력 키는 loopback API를 통해 서버 메모리에만 보관한다. 입력은 전송을 시작한 직후 비운다. 브라우저 저장소·파일·레지스트리에 저장하지 않는다. 서버 종료 시 사라진다. `GEMINI_API_KEY`가 있으면 값 대신 `환경변수 키 사용 중`만 표시한다. 새 화면 입력이 환경변수보다 우선하며 빈 키 입력은 현재 키를 유지한다. `키 지우기`는 화면 키와 현재 서버에서의 환경변수 키 사용을 모두 중단한다. 환경변수 자체를 변경하지 않으므로 재시작하면 환경변수 키는 다시 설정된다.

기본 상한은 UTC 일일·서버 세션 각 30회다. 0이면 요청을 보내지 않는다. 시험·실패·게임 호출을 같은 예산에서 예약한다. 설정·모델·키·모드 변경과 게임 리셋은 세션 사용량을 초기화하지 않는다. UTC 일일 호출 수만 기존 `artifacts/llm-usage.json`에 기록하며 키는 기록하지 않는다. 한도 감소는 즉시 적용되고, 증가는 이전 사용량을 보존한 채 적용된다. 호출 수는 공급자의 과금 상한이 아니다.

설정 적용·키 지우기·시작 모드 선택은 새 게임을 준비한다. 실행 중 요청은 기존 엔진의 요청 버전과 HTTP 세대 검사로 늦은 응답을 무시한다. 시험 중 설정이 바뀌면 시험을 취소하고 결과를 폐기한다. 실제 전송이 시작된 요청은 취소해도 예산을 환불하지 않는다.

## 로컬 API

모든 POST는 `application/json`, 정확한 필드 집합, 기존 Host/Origin 검사와 16KiB 본문 제한을 사용한다. 응답은 `no-store`다.

| 경로 | 본문 / 의미 |
| --- | --- |
| `GET /api/llm/status` | `keyConfigured`, `keySource` (`screen/env/none`), 모델·상한·시험 결과·모드. 키 값·일부·길이 없음 |
| `POST /api/llm/settings` | `{model, key, limit}`. 모델 1~200자 영문/숫자/점/밑줄/하이픈, 키 최대 512자(공백·제어문자 거부), 상한 정수 0~10000 |
| `POST /api/llm/test` | `{}`. 클릭당 최대 1회，설정·예산이 없으면 0회 |
| `POST /api/llm/clear` | `{}`. 현재 키 사용 중단, Mock 복귀 |
| `POST /api/llm/start` | `{mode: "mock"}` 또는 `{mode: "ai"}`. 호출 없이 새 게임 준비 |

`SecretGuard`를 재사용해 모델 ID와 공개 HTTP 응답의 키·부분·인코딩 반사를 차단한다. 키를 지운 뒤에도 이전 키 guard는 서버 세션 동안 남아 늦은 반사를 차단한다. 기존 공급자/평가 export 경계의 guard도 유지한다. 임의 암호화·변형을 모두 막는 일반 DLP는 아니다.

## 검증

`node scripts/verify-start-screen.ts`는 설치된 Edge에서 1920×1080 / 1366×768의 세 페이지를 촬영하고 페이지 스크롤·내용/버튼 가림·16px 본문·키보드/초점·Mock/AI 시작·기존 궁정 배치 동일 여부를 검사한다. 연결 결과는 가짜 transport로 주입하고 브라우저의 외부 요청을 거부한다. HTTP 응답·DOM·localStorage·usage·빌드 산출물은 합성 키 guard로 검사한다. 결과와 PNG는 `artifacts/start-screen/`에 저장한다.

기존 화면 검증은 `?start=court`로 바로 궁정에 진입한다. 이 경로는 기존 테스트의 엔진·공급자 주입을 유지하기 위한 시험용이며 실제 사용자는 첫 화면에서 모드를 선택한다. 기존 검사 조건은 약화하지 않는다. `node scripts/verify-all.ts`에 새 검사도 포함한다. 외부 API·계정·결제·실제 모델·한국어 품질은 라이브 미검증이다.
