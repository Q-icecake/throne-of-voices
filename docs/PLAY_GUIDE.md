# 첫 15분 플레이 가이드

`.\run.ps1 dev` 또는 `node scripts/dev.ts`로 실행하고 <http://127.0.0.1:5173>을 연다. 기본 Mock은 키가 필요 없다. 역사·대사·수치는 검토 전 시험용 재구성이다. 추천 전략보다 자신의 결정을 시험해 보는 것이 목적이다.

## 시작과 급보

평온한 정무청에서 아래 입력란으로 장굉에게 묻거나 지시할 수 있다. Enter는 줄바꿈, ‘전하기’는 제출이다. 오른쪽의 접견·문서·지도·명령·기록을 자유롭게 연다. 문서나 지도를 열어도 작성한 문장은 남는다. 장조를 기다리지 않고 주유·노숙을 직접 부를 수 있다.

화면 준비 뒤 **활성 25초**에 형주 급보, 40초에 조조 측 서신, 45초 장조 건의문, 50초 장조 요청, 60초 주유 보고, 65초 주유 요청이 온다. 상태에 따라 접견 요청은 대기/취소된다. 알림과 배지로만 전달하며 문서·접견을 강제로 열지 않는다. 받은 문서의 출처·관측 시각·도착 시각·불확실성을 확인하자. ‘시각 미상’은 0초라는 뜻이 아니다.

5분 이후에는 미답 회신의 재촉, 8분 이후에는 실제 미결 사항 요약이 생긴다. 회답이 전달 완료되면 낡은 재촉은 취소된다. 아무 결정도 하지 않아도 자동 패배하지 않으며 15분 후에도 플레이할 수 있다.

## 입력 예시 10개

아래 표의 세 번째 열은 오프라인 자동 검사에 사용하는 실제 Mock 분류다. `draft`는 초안 작성까지만 뜻한다. 질문으로 분류된다고 해서 일반 한국어에 대한 유용한 AI 답변을 보장하지 않는다. 네 인물의 대화는 작성된 답변/지식 경로를 사용한다.

| 써 볼 문장 | Mock에서 가능한 것 | 검사 분류 |
|---|---|---|
| `항복하면 어떻게 돼?` | 질문, 실행 없음 | `question` |
| `주유에게 수군을 정비하라고 전해. 먼저 공격하지는 마.` | 정비·선제공격 금지 초안 | `draft` |
| `공격하지 말고 수군만 정비해` | 정비만 초안, 공격 없음 | `draft` |
| `노숙은 유비에게 비밀리에 연락해. 참전은 약속하지 말고.` | 비밀 타진·참전 약속 금지 초안 | `draft` |
| `조조에게는 당장 확답하지 말고 5분 이내 시간을 벌어.` | 기한 있는 보류 초안 | `draft` |
| `조조에게 "논의 후 답하겠다"라고 회신해.` | 인용문을 전하는 회신 초안 | `draft` |
| `조조에게는 당장 확답하지 말고 시간을 벌어. 노숙은 유비에게 비밀리에 연락하고, 주유는 수군을 준비시키되 먼저 공격하지는 마.` | 세 행동 복합 초안 | `draft` |
| `정찰대를 보내` | 미지원, 기록만 남김 | `unsupported` |
| `세금을 걷어` | 미지원, 실행 없음 | `unsupported` |
| `그 사람을 보내` | 이 표현은 Mock 미지원, 이름·구체적인 지원 행동으로 다시 입력 | `unsupported` |

`장조와 주유를 함께 불러 의견을 듣자` 같은 회의 호출 문장은 Mock 명령으로 실행되지 않는다. 아래 접견 화면을 사용한다. 낯선 표현이 거절되면 초안의 범위를 확인하고 위 예시처럼 고쳐 입력한다. Mock 성공을 자유 문장 이해 능력으로 해석하지 않는다.

## 접견·회의·공유·실행

‘접견’에서 단독 접견을 누른다. 요청 배지는 기다리는 인물 수다. 요청의 ‘연기’는 맨 뒤로 한 번 이동한다. 접견 중인 인물을 연기하면 퇴실하고 재접견 대기열로 간다. **요청도 없고 접견 중도 아닌 인물은 연기할 수 없다**는 안내가 나오며 미래 요청을 만들지 않는다. 요청 전 거절은 미래 요청을 취소하는 명령이 아니다. 직접 호출은 언제나 현재 임무·가용성을 검사한다.

두세 명의 ‘회의 참석’을 선택해 ‘선택한 인물과 회의’를 누른다. 인물/명패를 눌러 발언 대상을 바꾼다. ‘둘이 논의해 봐’는 짧은 답변과 반론 뒤 입력권을 돌려주며 무한 토론하지 않는다. 자연어를 통한 자동 회의 호출은 지원하지 않는다.

문서를 열어 읽기만 하면 다른 인물에게 전달되지 않는다. 접견 중 문서 아래의 ‘○○에게 보여 주기’를 눌러 명시적으로 공유한다. 허용 목록 밖 공유는 거절한다. 공유 취소로 상대가 이미 배운 내용을 지우는 기능은 없다.

초안에서 대상·담당·비밀/공개·금지 조건·기한·비용·실행 범위를 읽고 확인한다. 수정·취소가 가능하며 패널을 닫는 것만으로 실행되지 않는다. 일부 미지원 요청은 제외 범위를 명시하고 부분 실행 동의를 요구한다. 같은 확인을 두 번 보내도 작업·소모는 한 번이다.

확인 후 명 전달 → 착수/출발 준비 → 진행 → 완료 보고로 바뀐다. 정비는 전달 10초+수행 30초, 유비 타진은 전달 5초+준비 10초+이동 15초+회신 대기 30초의 임시 시험 규칙이다. 접촉 성공은 자동 동맹·참전이 아니다. 처리 기록에서 원인을 찾고 관련 보고를 열어 실제 관측 시점을 읽는다. 첫 실행 이후 후속 보고 열람은 오프닝 관찰 지표이며 승리 판정은 아니다.

## 시계와 로컬 시험 도구

정상 실행은 자동 시계다. 입력 중·AI 대기·미확인 초안·수동 보류·백그라운드 동안 활성 시간이 멈춘다. 문서 읽기는 시간 자체를 멈추지 않는다. 긴 독서에는 ‘시험 도구’의 수동 보류를 쓴다. 문서 읽는 중에는 약한 도움 안내만 억제된다.

시험 도구에서 자동/수동 시계를 바꾸고 +5초/+30초 또는 ‘다음 사건’을 누른다. 다음 사건은 가장 가까운 사건/작업 경계까지만 진행하며 모든 임무를 끝내지 않는다. 보류 사유가 남아 있으면 시간 전진보다 보류가 우선이다. 리셋은 현재 세션을 초기화한다. 서버 재시작도 새 세션이며 이전 플레이는 저장하지 않는다. 시험 도구는 로컬 개발용이다.

자동 재현: `.\run.ps1 verify`. 결과/스크린샷은 `artifacts/m6/`에 있다. 세부 결과는 [QA 매트릭스](QA_MATRIX.md), 범위는 [알려진 한계](KNOWN_LIMITS.md), 12개 설계 변형은 [PLAYTHROUGH](PLAYTHROUGH.md)와 `content/opening/test-scenarios.json`을 참고한다.

## 사람 시험 시나리오 3가지

1. **기본 동선 (15분)**: 아무 추천 전략 없이 첫 화면에서 스스로 질문·문서·접견을 찾아본다. 급보 이후 장조·주유 의견을 듣고 필요하면 회의와 공유를 한다. 스스로 고른 지원 명령을 확인하고 보고를 읽는다. 첫 질문/명령까지 걸린 시간과 도움 횟수를 관찰자가 기록한다.
2. **주유 먼저·조기 명령 (15분)**: 시작부터 장조를 건너뛰고 주유를 부른다. 첫 2분 안에 비밀 유비 타진이나 수군 정비를 지시한다. 다른 인물의 선행 접견을 강요하는지, 비밀·금지 조건이 초안부터 보고까지 남는지, 결과의 원인을 설명할 수 있는지 확인한다.
3. **아무 결정도 안 함 (15분 이상)**: 명령을 확정하지 않고 문서와 지도를 읽거나 기다린다. 5분 재촉·8분 미결 요약과 배지의 의미, 압박이 결정 강요처럼 느껴지는지, 15분 이후에도 입력 가능한지 관찰한다. 실제 활성 시간과 보류 중 벽시간을 구분해 기록한다.

처음에는 역사 지식이 많지 않은 3~5명에게 기본 조작만 설명하는 관찰 시험을 제안한다. 아직 실제 사람 시험은 수행하지 않았다. 익명 세션 ID, 첫 질문·첫 명령 시간, 원하는데 못 한 행동, 재입력·수정 횟수, 가장 긴 기다림, 설명할 수 없는 결과, 다시 해보고 싶은 선택을 적는다. 녹음·개인정보는 기본 기록에 포함하지 않는다.

마지막에는 다음을 묻는다: “네 명령이 실제 어떤 일로 바뀌었나?”, “어디에서 자유롭지 못했나?”, “다르게 해보고 싶은 결정은?”, “문서의 확실한 정보와 추측을 구별했나?”, “기다리는 동안 무엇을 할 수 있는지 알았나?” 기술적 진행이 막히지 않아도 자유로운 결정의 재미가 없으면 기획 검토가 필요하다. 공간감·인물 표현의 질·긴장·재미는 자동 판정할 수 없다.
