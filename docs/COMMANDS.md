# M3 명령 — 시험용 행동·조건·상태

서버가 검증·실행한다. 기본은 제한된 한국어 패턴을 인식하는 Mock이며, ScriptedProvider는 M2 비동기 파이프라인의 고정 응답 시험이다. 일반 자연어 이해 성능이나 실제 AI 품질을 입증하지 않는다. 수치·회신은 역사 사실이 아닌 시험용 재구성이다.

| 행동 | 수행자 / 대상 | 비용·시간 (활성 시험 시계) | 실제 결과 |
|---|---|---|---|
| `naval-drill` | 주유 / 강동 수군 | 군량 100, 전달 10초 + 정비 30초 | 착수 때 1회 소모, 완료 때 준비도 +15. 교전 없음 |
| `hold-reply` | 장굉 / 조조 사신 | 군량 0, 전달 5초 + 처리 5초 | 요청 `pending → held/answered`, 보류 기한·전언 기록. 기본 보류 120초. 항복·조약 자동 성립 없음 |
| `sound-out` | 노숙 / 유비 측 | 군량 20, 명 전달 5초 + 준비 10초 + 이동 15초 + 회신 대기 30초 | 명 전달 → 출발 준비 → 전달 중 → 회신 대기 → 회신 도착. 즉시 동맹 없음 |

비용·시간·유비 측 반응은 `server/rules.ts`에서 정한다. 회신은 고정된 추가 논의 요청이다. 시계 전진이 작업 임계 시각을 순서대로 처리하며, 범용 사건 스케줄러는 구현하지 않는다.

- **조건:** `secret`/`public`, `no-first-strike`, `no-war-promise`, `no-firm-answer`. 비밀은 보고 열람자와 전언 수신자를 제한한다. 선제공격 금지는 교전 방침에 적용한다. 참전 약속 금지는 유비 전언과 모든 진행 보고에 남긴다. 원문에 없는 제한은 추가하지 않는다.
- **기한:** `N분 이내` (1~999), 초안 작성·수정 시 활성 시각 기준 완료 기한. 확인 때 선행 작업을 포함해 재검사한다. 조조 보류는 지정 기한까지 유지한다. 달력 날짜·임의 조건식은 미지원으로 되묻는다.
- **선후관계:** 뒤 행동의 `그 뒤`, `그 후`, `다음에`, `완료 후`는 앞 행동 완료 후 시작 (`after:0/1`). 선행 작업이 중단되면 후속 작업도 중단한다.
- **회신:** `조조에게 "논의 후 답하겠다"라고 회신해.`처럼 원문에 명시한 따옴표 안 문구만 `message:`로 전달한다. 회신 문구가 없으면 미해결로 남긴다.
- **확인:** 한 초안은 서로 다른 행동 최대 3개. 더 길거나 같은 행동을 반복하면 나누어 확인한다. 미지원·모호 부분은 별도로 표시하며, `표시된 행동만 확인 · 미해결 제외`로 실행 범위를 명시한다 (`acceptPartial: true`). 일반 확인으로는 부분 실행하지 않는다.
- **안전한 실행:** 확인 전 작업·소모 없음. 확인 때 최신 담당자 충돌, 예약된 군량, 기한을 모두 검사한다. 하나라도 충돌하면 묶음 전체 반려. 같은 초안 버전을 재확인해도 기존 작업 ID만 반환한다. 소모 이벤트는 작업당 1개다.
- **수정·취소·회수:** 초안 수정은 버전을 올리고 취소는 실행을 막는다. 확인 후 `회수 요청`은 작업에 연결된 요청·보고·이벤트로 남긴다. 명 전달 전·출발 준비 중에는 중단 가능. 이미 소모한 군량, 생성한 문서, 전달한 전언은 보존한다. 출발·정비 착수 이후는 요청 기록만 지원하며 기존 작업은 계속된다. 중복 회수 요청은 추가 효과가 없다.
- **상태:** 초안 `awaiting-confirmation/confirmed/cancelled/rejected`; 작업 `waiting/delivering/preparing/travelling/awaiting-reply/in-progress/completed/stopped`. 각 진행 보고에 작업 ID를 붙인다. 플레이어 지식과 인물별 지식은 허용 필드·열람자 목록으로 분리한다.

예: `조조에게는 당장 확답하지 말고 시간을 벌어. 노숙은 유비에게 비밀리에 연락하고, 주유는 수군을 준비시키되 먼저 공격하지는 마.`

이 예는 확답 보류·비밀·선제공격 금지만 포함한다. `참전은 약속하지 말고`를 명시한 변형에서만 참전 약속 금지를 추가한다. 조기 명령, 수군만, 조조 답변만, 노숙만 지시해도 접견 순서 없이 실행한다.

**미지원:** `scout` 정찰, 전투·공격·암살·정치개혁, 임의 담당자·대상 변경, 일반 자연어/임의 조건·날짜의 완전한 해석, 출발 후 실제 회수, 이미 공개한 정보의 삭제, **문서 공유 취소**(이미 알려진 정보·공유 사건·관계 변화는 유지), 실제 LLM 호출, 자동 급보·보류 기한 만료 사건(M5). 인물 대화는 M4의 `docs/CHARACTERS.md` 범위에서 지원한다. 미지원 행동을 성공으로 표시하지 않는다.

**R1 보완:** `비공개로`, `비밀리에`, `몰래`, `은밀히`는 비밀로 판정한다. 한 절의 공개/비밀 혼재·공개 부정은 범위를 되묻고 실행 초안을 만들지 않는다. Provider 검증도 원문을 다시 파싱하여 추가·누락 행동과 조건을 대조한다. 수군 기본값은 제거했으며 기존 평가 문장의 배·병선·채비·손보기 표현은 명시적인 원문 근거로만 인정한다. 같은 절의 서로 다른 행동은 모두 보존하고, 알려진 표현을 제외한 나머지 요청(세금 징수·병사 모집 등)은 미해결로 표시한다. 보수적인 유한 패턴이므로 낯선 문구는 과도하게 미해결로 남을 수 있다.

비밀 작업의 보고는 권한 있는 플레이어 화면에 유지하지만, 후속 Provider 해석에는 해당 보고와 비밀 명령의 대화 이력·수정 전 원문을 자동 첨부하지 않는다. 현재 사용자가 직접 제출한 명령은 해석 입력으로 전달한다. 단독/복합 초안은 같은 공개 범위·기한·제한 표시를 사용하며, 원문/상세/편집 영역만 스크롤된다. 범위를 지정하지 않으면 기존 공개 실행 동작을 유지하고 화면에 공개로 표시한다.

R2a: 같은 전송 정책을 M4 대화의 보고·사건 기억·요약에도 적용한다. 비밀 임무 당사자의 보고/기억 질문은 당사자만 있는 접견에서 실제 엔진 근거로 로컬 처리하고, 외부 Provider로 자동 보내지 않는다. 다른 인물에게 문서를 공유해도 자동 전송 예외가 생기지 않는다. 확정 당시의 미완료 기억 뒤에 실제 진행·완료·회수 사건을 추가한다. 모델의 실행 결과 단정과 내부 카드 ID는 공통 출력 필터에서 차단한다.
