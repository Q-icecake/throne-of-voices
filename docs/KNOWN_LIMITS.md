# 알려진 범위와 한계 — M6

## 구현된 범위

로컬 단일 메모리 세션, 네 인물(장굉·장조·주유·노숙) 접견과 두세 명 회의, 인물별 지식·사건 근거 기억, 명시적 문서 공유, 받은 보고에 근거한 지도, 명령 초안/수정/취소/확인, 최대 세 행동 복합 명령, 조조 회신·보류/기한, 비밀 유비 의중 타진, 수군 정비/선제공격 금지, 작업 전달/진행/회신 보고, 조건부 오프닝 사건과 시간 보류가 있다. 15분은 관찰 길이이며 종료 시한이 아니다.

접견 요청은 인물별 유일하다. 미요청·미접견 인물을 미리 연기해 미래 요청을 만드는 행위는 허용하지 않는다. 접견 중 연기는 퇴실·재접견 대기를 뜻한다. 거절은 현재 대기 요청만 제거한다. 이미 알려진 정보를 공유 취소로 지우거나 이미 출발한 임무를 실제 회수하는 기능은 없다. 회수 미지원 요청과 과거 소모·전달은 기록에 남는다.

## 미지원·부분 지원

- 전투, 승패 캠페인, 정찰, 정치 개혁·세금·암살 등 범용 통치, 음성 입력/ASR, 저장/불러오기, 다중 사용자/다중 탭 동시 제어는 구현하지 않았다.
- Mock은 유한 한국어 패턴과 작성된 대사를 사용한다. 문장 전반의 자유로운 의미 이해를 검증하지 않는다. 일부 Mock 오류 문구에는 초기 M1/M2 단계명이 남아 있다. 자연어 회의 호출은 접견 화면 조작으로 대체한다.
- 날짜·군량·준비도·진행 시간·외교 회신은 고정 시험 규칙이다. 유비 타진은 동맹 확정이 아니다. 문서의 정보는 관측 시점의 범위이며 숨은 실시간 세계 상태를 보여 주지 않는다.
- 문서 목록과 긴 본문은 패널 내부 스크롤을 사용한다. 페이지 자체는 스크롤하지 않는다. 작은 화면에서 목록 아래 본문을 읽으려면 패널을 내려야 한다. 1366 지도는 의도적으로 화면의 약 55%를 덮는 임시 열린 패널이다.
- 개발 도구와 HTTP 시험 API는 로컬 프로토타입용이다. 인터넷 서비스·공개 배포·영구 저장 서비스로 검증하지 않았다.
- soak는 12회 × 960초 **가짜 활성 시계** 시험이다. 실제 수 시간 운영, 장기 메모리/CPU 프로파일링, 다중 탭 경합을 증명하지 않는다. 입력별 감사 로그는 의도적으로 증가하며 한 세션을 영원히 운영하면 무제한 저장 방지 정책은 별도로 필요하다. 고정 입력 이후 사건·문서·요청의 자발적 증가는 검사했다.

## 라이브 미검증

R3 대화 검사는 완료·체결·출발·합의 등의 어간과 과거/존대/진행 활용을 절 단위로 탐지한다. 탐지된 사실은 현재 대화방에서 열람 가능한 보고의 작업 ID와 엔진 진행 사건을 대조하여 생성한 고정 문장과 정확히 일치할 때만 허용한다. 실제 정비 완료가 있어도 동맹 체결이나 다른 인물의 완료를 뒷받침하지 않는다. Provider가 낸 근거 ID·대화 기록·사용자가 쓴 전언은 사실 증명이 아니다. 오프라인 답변의 명시적 기록 인용은 현재 열람 가능한 원문과 따로 대조한다. 검증 불가 답변은 인물별 고정 문구로 대체하고 원문 없이 대체 사실만 로그에 남긴다.

한국어 의미 전체를 판별하지 못한다. 알려지지 않은 동사·비유·복잡한 인용/부정/조건에는 누락이나 오탐이 가능하며, 사실인 동의어도 고정 근거 문장과 다르면 거절할 수 있다. 이 필터는 라이브 AI의 **보조 장치**일 뿐 범용 사실성 보장이나 한국어 이해 검증이 아니다. 계획·가정·조건과 정상 문장 회귀는 제한된 오프라인 표본이다.

실제 외부 LLM 호출은 이번 단계 **0회**다. Gemini 어댑터·설정·타임아웃·호출 제한·복구는 가짜 fetch/ScriptedProvider로 검사했다. 실제 계정 모델 접근, 현재 무료/유료 한도, 실제 구조화 출력, 한국어 해석·대사의 품질, 지연·요금은 라이브 미검증이다. 키가 없으면 라이브 평가를 실행하지 않는다. 승인된 환경의 설정·평가 절차는 README와 `server/llm/README.md`에 있다.

`eval-llm.ts`는 30문장의 의도·행동·금지 제한을 자동 비교하지만 조건 배열 전체는 성공 판정에 포함하지 않는다. 따라서 승인 후 평가에서도 원문과 secret/기한/선후 조건을 사람이 추가 대조해야 한다. 오프라인 AI 표시는 재생 시험 출처이며 실제 모델 호출 성공의 증거가 아니다.

## 임시 아트와 사람 대조

| 대상 | 현재 상태 | 남은 확인 |
|---|---|---|
| 손권 | 기존 단순 SVG 인물, 고정 좌석 | 인물 표현·시대복식·비례의 사람 평가 |
| 호위 2인 | 기존 단순 SVG 실루엣 | 자세·복식·자연스러움의 사람 평가 |
| 장굉 | 가져온 임시 SVG 초상과 실패 대체 그림 | 표현 품질·다른 인물과 일관성 |
| 장조·주유·노숙 | 임시 SVG 표현·명패, 회의 실루엣 | 인물 구분·공간 배치의 사람 평가 |
| 궁정·전경·지도 | 승인된 SVG 시각 방향의 시험 자산 | 공간감·가독성·사료와의 대조 |

이번 단계에서 손권·호위 아트와 시각 방향은 재작업하지 않았다. CK3 참고 이미지는 제품에 포함하지 않는다. 한국어 본문 크기·CSS 대비·가림 면적은 수치로 검사하지만 글꼴 렌더링·문장 자연스러움·공간감·인물 표현의 질은 자동 판정할 수 없다.

역사 문서와 대사는 **시험용 재구성, 사람의 사료 대조 필요**다. 실물 사료의 번역문이나 확정된 역사 수치로 취급하지 않는다. 실제 IME·다른 브라우저·접근성 보조기술 전체·사람의 15분 재미와 긴장은 미검증이다. 실제 마지막 자동 결과와 남은 사람 검증은 `QA_MATRIX.md`를 따른다.
