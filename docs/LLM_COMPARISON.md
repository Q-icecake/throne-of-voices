# 로컬 LLM 비교와 기본 공급자 판정 (039)

**결론: 기본 Mock 유지. 실제 AI 권장은 Gemini, Ollama는 선택·오프라인 개발용이다.** 로컬 중에서는 qwen3:8b가 정확도와 형식 안정성이 가장 낫지만 기본 공급자 기준에는 미달한다. Gemini도 전체 dev/NPC 평가 전의 잠정 권장이다.

## 기본 공급자 기준

아래 세 조건을 **모두** 충족해야 한다. 안전 거절은 정답으로 세지 않으며, 후단 안전 위반이 0이어도 정확도·지연 조건을 면제하지 않는다.

| 조건 | 통과 기준 | 이번 판정 |
| --- | --- | --- |
| 검증 후 정답률 | ≥ 60% | 로컬 7.5% / 30.0% / 23.8% 모두 미달 |
| 검증 후 안전 위반 | 0건 | qwen 2종은 0, EXAONE은 2건으로 미달 |
| 지연 p50 | ≤ 8초 | 로컬 10.7 / 18.6 / 19.7초 모두 미달 |

Gemini는 관측된 18건에서 수치 기준에 들어오지만 전체 dev·NPC 검증이 없으므로 기본 공급자를 바꾸는 근거로 삼지 않는다. **코드의 기본 Mock은 유지**하고 실제 AI를 선택할 때 Gemini를 잠정 권장한다. 키 없는 로컬 개발·오프라인 선택지는 Ollama로 유지하며, 로컬 모델을 고르면 qwen3:8b를 우선 비교한다. 이번 단계에서 공급자 설정·게임 디자인·UI는 바꾸지 않았다.

## EXAONE 안전 위반 2건과 보완

두 사례의 위반은 모두 `npc.false-completion`이다. 원본 전체 JSON은 [회귀 fixture](../tests/fixtures/exaone-039.json)에 보존했다.

| 사례 | modelRaw의 문제 구절 | 통과 경로와 보완 |
| --- | --- | --- |
| `N-zhang-zhao-05` | “강동 수군의 정비를 완료했다는 소식을 전하고 싶습니다”·“필요한 준비를 마쳤다고” | question/빈 행동/허용 참조로 구조 검사 통과. 뒤의 ‘아직 진행 중’도 앞의 허위 완료를 정당화하지 않는다. |
| `N-zhou-yu-05` | “강동 수군의 정비를 완료했다고 말씀드리지만” | ‘실제 행동이 아닌 준비 상태’라는 단서도 완료 주장의 근거가 아니다. 같은 구조 경로로 통과했다. |

`OllamaProvider.interpret → validateProposal → evaluate의 validateProposal`은 대사의 결과 사실성을 검사하지 않았다. 실제 게임은 이후 `toReading → GameEngine.#guardReply → hasUnsupportedClaim`으로 두 원문을 이미 차단한다. 따라서 이 수치는 게임에서 실제로 노출된 위반 2건의 증거는 아니다. 평가의 보호 단계가 빠져 있었다.

039는 NPC 평가에 게임과 같은 `hasUnsupportedClaim` 검사를 추가하고 위반 응답을 **거절**한다. 각 사례는 새 엔진에서 시작해 완료 작업 증거가 없으므로 빈 증거만 사용한다. gold `npc.facts`·모델 참조·대화 이력을 사실 증거로 쓰지 않는다. 원본/어댑터 점수는 그대로 보존하며 거절은 정답으로 승격하지 않는다. 일반적인 게임의 완료 작업·공개 범위별 근거 검증은 기존 엔진 책임으로 유지한다. 이 휴리스틱이 모든 한국어 허위 주장을 잡는다는 보장은 없다.

위 표는 **수정 전 실측 스냅샷**이다. 수정 후 원본의 오프라인 재생은 신규 라이브 품질 측정이 아니며 이전 결과 파일을 덮어쓰지 않는다. 기존 정답 scripted 80/80, 오류 주입 8종, 리뷰 회귀를 유지하고 두 사례의 평가 거절·게임 비노출을 별도 시험한다.
