# 첫 15분 플레이 가이드 (M5 초안)

`node scripts/dev.ts` 또는 기존 `run.ps1`로 실행한다. 외부 LLM 호출은 필요하지 않으며 기본은 Mock 해석과 작성 대사다. 역사 내용은 시험용 재구성이고 사람의 사료 대조가 필요하다.

처음에는 평온한 정무청이다. 아래 입력란에서 장굉에게 질문하거나 지시할 수 있다. 문서·지도·접견·처리 기록은 오른쪽 도구에서 연다. 조작 설명 모달은 없다. 입력은 문서나 지도를 열어도 남는다.

준비 완료 뒤 활성 약 25초에 형주 급보가 한 줄 알림과 문서 배지로 도착한다. 문서를 자동으로 열지 않는다. 40초 서신, 45초 장조 건의문, 50초 장조 접견 요청, 60초 주유 보고, 65초 주유 접견 요청이 이어진다. 이는 최소 자격 시각이며 상태에 따라 요청은 대기하거나 취소된다. 문서의 출처·관측 시각·실제 도착 시각·근거 범위를 구분한다. 시각 미상은 0초가 아니다.

접견 요청은 도구 배지에서 확인한다. 수락하거나 연기·거절할 수 있고, 처음부터 주유나 노숙을 먼저 부를 수도 있다. 두세 명의 회의는 선택 사항이다. 문서를 읽는 것만으로 다른 사람이 알게 되지 않는다. 접견 중 문서의 ‘보여 주기’로 공유하며, 허용 목록 밖 인물에게는 전달하지 않는다.

입력 중·AI 응답 대기·미확인 초안·수동 보류·백그라운드에서는 활성 시간이 멈춘다. 문서 읽기는 시간을 자동으로 멈추지 않지만 장굉의 안내를 억제한다. 필요하면 시험 도구의 수동 보류를 사용한다. 시험 도구에는 자동/수동 전환, +5초/+30초, 다음 사건까지 시간 보내기가 있다. 다음 사건 버튼은 가장 가까운 콘텐츠 또는 작업 경계에서 멈추며 모든 임무를 완료시키지 않는다. 보류 중에는 보류가 우선이다.

예시 지시:

- `주유에게 수군을 정비하라고 전해. 먼저 공격하지는 마.`
- `노숙은 유비에게 비밀리에 연락해. 참전은 약속하지 말고.`
- `조조에게는 당장 확답하지 말고 시간을 벌어. 노숙은 유비에게 비밀리에 연락하고, 주유는 수군을 준비시키되 먼저 공격하지는 마.`

초안의 실행 범위·담당자·조건·비용을 검토한 뒤 확인한다. 초안만으로는 실행·군량 소모가 없다. 확인한 지시는 전달→착수/준비→진행→완료 보고로 이어진다. 정비는 전달 10초+작업 30초, 외교 타진은 전달 5초+준비 10초+이동 15초+회신 대기 30초의 시험 규칙이다. 마지막 관련 보고를 실제로 열면 첫 지시의 후속 반응을 관찰한 지표(T14)가 기록된다. 이는 승패 판정이나 종료가 아니다.

결정하지 않아도 5분 이후 미답 요청의 재촉과 8분 이후 실제 남은 사안만 쌓인다. 답변을 전달 완료했다면 같은 조조 요청을 다시 재촉하지 않는다. 보류 기한이 더 늦으면 그때까지 기다린다. 15분 후에도 계속 플레이할 수 있다. 유비 접촉을 하지 않았으면 노숙 출발 보고는 없다.

## 재현과 검증

`node scripts/playthrough.ts`는 `content/opening/test-scenarios.json`의 12개 설계를 명시적 조작 어댑터와 기존 Mock 명령으로 실행한다. 조작 설명 문장을 자연어로 이해했다고 주장하지 않는다. 별도 ScriptedProvider 대화도 외부 연결 없이 검사한다.

| 변형 | 관찰 항목 |
|---|---|
| S01 기본·회의·복합 명령 | 세 작업과 실제 후속 보고 |
| S02 주유 먼저 | 장조 없이 진행·첫 요청 취소 |
| S03 조기 유비 접촉 | 준비/출발 구분·노숙 안내 생략 |
| S04 수군만 | 노숙·회의 없이 첫 후속 반응 |
| S05 무결정 | 압박 누적·15분 이후 계속 |
| S06 답변 완료 | T11 취소·낡은 서신이 요청 재생성 금지 |
| S07 재현·중복 확인 | 동일 스냅샷·비용 1회 |
| S08 문서·공유 | 열람/수신/공유 구분·허용 상한 |
| S09 연기·무시 | 큐 변경·요청 재생성 없음 |
| S10 보류 연장 | 369999ms 없음·370000ms 재촉 1회 |
| S11 보류·안내 | 각 보류 사유·논의 후에만 약한 안내 |
| S12 취소 | 초안 취소 뒤 실행·소모 없음 |

`node scripts/verify-m5.ts`는 별도 포트 3101/5273와 설치된 Edge headless에서 1920×1080·1366×768을 검사한다. 첫 급보와 복합 명령 후속 보고는 실제 자동 시계를 기다린다. 압박 구간은 도구의 명시적 시간 전진을 사용한다. 결과·스크린샷: `artifacts/m5/`. 기존 `scripts/screenshots.ts`와 `scripts/verify-visual.ts`도 별도로 실행한다.

기존 `new GameEngine()`은 M1~M4 회귀용 수동 fixture를 보존한다. 개시 사건 시험은 생성자 여섯 번째 인수 `{ mode: 'manual' }`로 활성화하며, 정상 HTTP 서버는 자동·화면 준비 대기 상태로 생성한다. 시험 도구는 로컬 전용이다.

실제 LLM 품질·한국어 전반 이해·사료 정확성·IME·다른 브라우저·사람이 느끼는 긴장과 재미는 자동 검사로 증명하지 않는다. 실제 사람이 15분 플레이하는 관찰 시험이 필요하다.
