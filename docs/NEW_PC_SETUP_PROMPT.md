# 새 PC의 Claude Code 창에 붙여 넣을 설치 프롬프트

아래 전체를 새 Claude Code 창에 붙여 넣는다. 저장소 폴더를 먼저 열고 시작한다. API 키는 이 프롬프트·채팅에 붙여 넣지 않는다.

```text
Throne of Voices를 이 PC에서 설치하고 Mock으로 실행한다. 한국어로 결과를 보고하라.

1. 현재 열린 폴더가 저장소 루트인지 확인한다. HANDOFF.md, package.json, run.ps1, setup.ps1이 있어야 한다. 고정 F: 경로를 가정하지 말고 현재 저장소 위치를 기준으로 실행한다. HANDOFF.md와 docs/USB_PORTABILITY.md, docs/LLM_SETUP.md, docs/LLM_COMPARISON.md를 읽는다. 다른 프로젝트는 수정하지 않는다.

2. 먼저 powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1 -WhatIf -Verify 로 계획을 확인한다. PowerShell 7이면 pwsh로 같은 명령을 실행해도 된다. 실행 정책은 이 자식 프로세스에만 적용하고 시스템·계정 정책을 바꾸지 않는다.

3. Node.js 24 이상이면 .\setup.ps1 -Verify 를 실행한다. Node가 없거나 낮으면 .\setup.ps1 -InstallNode -Verify 로 설치한다. 설치 명령에는 인터넷이 필요하며 winget/설치 권한이 필요할 수 있다. 설치 후 현재 창에서 Node를 찾지 못하면 새 터미널에서 다시 실행한다. winget이 없으면 원인과 Node 수동 설치 방법을 보고한다. 키·로그인·결제·계정 변경을 진행하지 않는다.

4. 설치 결과의 typecheck/test가 모두 통과했는지 확인하고 .\run.ps1 build 를 실행한다. 실패를 성공으로 보고하지 않는다. 실패 원인과 다음 명령을 적는다. .\run.ps1 dev 를 시작하고 터미널에 출력된 로컬 주소를 브라우저로 연다. 첫 화면에서 Mock으로 시작해 명령 초안·확인 흐름을 점검한다. 서버 포트가 다르면 출력된 실제 주소를 따른다.

5. 기본 Mock은 키·모델 다운로드 없이 동작한다. 실제 AI는 선택이다. 설치 기본값을 바꾸지 않는다.
   - Ollama를 원할 때만 .\setup.ps1 -WithOllama -Verify 를 실행한다. 기본 모델 qwen3:8b는 약 5.2GB, 저장 드라이브 여유 10GB 이상을 권장한다. 크기·실제 저장 위치·PC 메모리에 따라 다르다. 다른 모델은 -OllamaModel로 명시한다. Ollama는 선택·오프라인 개발용이고 현재 로컬 실측은 기본 공급자 기준에 미달한다. 설치·서비스·모델 확인 성공과 실제 추론 품질은 구분한다. 게임 첫 화면의 AI 연결 설정에서 Ollama 선택 → 설치 모델 목록 → 설정 적용으로 연결한다. 실제 추론 시험은 사용자가 원할 때 한 번만 한다.
   - Gemini를 원하면 docs/LLM_SETUP.md를 따른다. 실제 AI의 잠정 권장 공급자다. 사용자가 키를 게임 첫 화면에 직접 입력하거나 현재 PowerShell 창의 환경변수에만 설정하게 한다. 키를 채팅에 요청하지 말고 .env/파일/영구 환경변수/로그/커밋에 저장하지 않는다. 연결 시험과 라이브 평가는 외부 사용량을 차감하므로 자동으로 실행하지 않는다. 결제·로그인·인증·계정 설정이 필요하면 멈추고 이유를 보고한다.

6. 선택·확인 팝업을 띄우지 않는다. 도구나 브라우저 이름처럼 작고 명확한 차이는 판단해 계속하고 보고에 적는다. 정말 사용자가 결정해야 하는 결제·외부 공개·로그인·인증·계정 설정이 필요하면 본 작업을 끝내고 차단 이유만 보고한다. push·배포는 하지 않는다.

보고 형식:
- 저장소 위치 / Node 버전 / 설치 선택 사항
- 실제 실행한 명령과 종료 코드
- typecheck·test 개수·build / 실행한 게임 주소·Mock 점검 결과
- Ollama 설치·서비스·모델 확인(선택 시), 실제 추론은 실행/미실행 구분
- 실패·미검증·사용자에게 필요한 다음 단계
- 비밀 값을 출력·저장하지 않았는지 확인(값은 쓰지 않음)
```

`setup.ps1`은 스크립트 폴더를 기준으로 실행하므로 USB 경로에 공백·한글이 있어도 된다. `-WhatIf`(`-DryRun`)는 설치·접속 없이 계획만 표시한다. 정상 실행의 의존성 설치는 기존 `run.ps1 install`을 재사용한다. 자동 Node 설치는 `-InstallNode`, Ollama 설치·서비스·모델 다운로드는 `-WithOllama`를 명시했을 때만 실행한다.
