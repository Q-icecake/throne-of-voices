# Throne of Voices — M0

`DEVELOPMENT_PLAN.md`의 **M0 실행·시험 기반**만 구현한 로컬 시제품입니다. 실제 AI 호출, 명령 해석·실행, NPC 대화와 15분 시나리오는 아직 없습니다. 원래 설계 문서는 수정하지 않았습니다.

## 실행

현재 PC에는 의존성이 설치되어 있습니다. 프로젝트 폴더에서 PowerShell을 열고 실행하세요.

```powershell
.\run.ps1 dev
```

[로컬 화면 열기](http://127.0.0.1:5173) — 개발 서버가 실행 중이어야 합니다. 종료는 터미널에서 `Ctrl+C`입니다. API는 `127.0.0.1:3001`에서 함께 실행됩니다. 다른 프로그램이 포트를 사용하면 자동으로 다른 포트로 옮기지 않고 시작 오류를 표시합니다.

Node.js 24 이상이 필요합니다. `run.ps1`은 PATH의 Node를 우선 사용하고, 없다면 이 PC의 Codex 기본 Node 경로를 확인합니다. 서버 코드를 바꾸면 개발 서버를 다시 시작하세요. 화면 변경에는 Vite HMR이 적용됩니다.

처음 설치하거나 의존성을 복원하려면:

```powershell
.\run.ps1 install
```

설치 스크립트는 설치된 pnpm 또는 Codex에 포함된 pnpm을 사용합니다. 다른 PC에서는 Node.js 24 이상과 pnpm 11.25.0을 준비한 뒤 `pnpm install --frozen-lockfile`로 설치해도 됩니다. `pnpm-lock.yaml`이 설치 버전을 고정합니다. 직접 의존성은 Vite, TypeScript, Node 타입 세 개뿐이며 LLM SDK는 없습니다.

표준 패키지 스크립트도 제공합니다: `pnpm dev`, `pnpm test`, `pnpm build`, `pnpm snapshot`.

## 시험 방법

```powershell
.\run.ps1 typecheck
.\run.ps1 test
.\run.ps1 build
.\run.ps1 snapshot
```

- **시계 +5초:** 벽시계와 무관한 고정 밀리초를 서버에 전달합니다. 수동 보류 중에는 활성 시간이 증가하지 않고 보류 시간이 증가합니다.
- **Mock 응답 확인:** 어떤 문장에도 시험용 고정 응답을 반환합니다. 자연어 해석 능력 시험이 아니며 명령·자원·외교·수군 상태는 바꾸지 않습니다. 요청 이력과 상태 버전만 증가합니다.
- **초기 상태로 재시작:** 세계 상태·시계·로그를 동일한 fixture로 되돌립니다. 서버 재시작도 같은 결과입니다.
- **공개 스냅샷/로그 저장:** 실행 중인 세션의 플레이어 공개 JSON을 브라우저 다운로드 폴더에 저장합니다.
- **상태 다시 읽기:** 서버 재시작 또는 요청 실패 후 현재 공개 상태를 다시 가져옵니다. 실패한 Mock 입력은 지우지 않습니다.
- **로컬 전체 스냅샷:** `snapshot` 명령은 별도 고정 시퀀스를 처음부터 실행하고 `artifacts/m0-internal-snapshot.json`, `m0-public-snapshot.json`, `m0-replay.json`을 생성합니다. 실행 중인 브라우저 세션을 조회하는 명령이 아닙니다. 내부 스냅샷에는 이벤트 원인과 원문 입력도 들어갑니다. 이 파일은 개발 서버가 제공하지 않습니다.

`build`는 `dist/`에 프런트엔드 산출물을 만듭니다. `dist/index.html`을 파일로 직접 열면 API가 동작하지 않습니다. M0의 지원 실행 방법은 `dev`이며 외부 배포·운영 서버는 범위 밖입니다.

## 구조와 경계

| 파일 | 역할 |
|---|---|
| `client/index.html`, `client/src/main.ts`, `client/src/style.css` | 한국어 HTML UI, SVG 개념도, 공개 상태 표시, 시험 조작 |
| `shared/contracts.ts` | 브라우저와 서버 사이의 공개 데이터·시험 요청 형식 |
| `server/world.ts` | 최소 WorldState와 고정 초기 상태. 내부 자원·수군 상태·인물 위치·비공개 자료 |
| `server/engine.ts`, `server/clock.ts` | 유일한 상태 소유자, 재시작, 가짜 시계, 재현 가능한 사건 기록 |
| `server/knowledge.ts` | 열람 권한과 필드 허용 목록으로 만든 KnowledgeView·PlayerView |
| `server/provider.ts` | 공급자 인터페이스와 명시적 MockLLMProvider |
| `server/http.ts`, `server/index.ts` | 로컬 Node HTTP API, 입력 검증, 오류 응답 |
| `scripts/dev.ts`, `scripts/snapshot.ts`, `run.ps1` | 실행·시험 도구 |
| `tests/*.test.ts` | 재현성, 오류, 공개 경계, HTTP, 개발 서버와 빌드 검사 |
| `vite.config.ts`, `tsconfig.json`, `package.json`, `pnpm-lock.yaml` | 실행·타입·의존성 설정 |

세계 상태는 Node 서버 메모리에만 존재합니다. 브라우저가 받은 상태를 통째로 덮어쓰는 API는 없습니다. Provider에는 별도로 복사한 허용 지식만 전달하며, 응답 대사는 상태 변경의 근거가 되지 않습니다. Mock 요청은 동기식 고정 응답이며 실제 모델의 지연·재시도·스트리밍을 모사하지 않습니다.

Vite의 제공 루트를 `client/`로 제한하고 공유 계약 외의 서버 코드·시험 코드·내부 산출물 접근을 차단합니다. `.env` 자동 로드와 사용자 환경변수의 클라이언트 노출을 비활성화했습니다. API 키를 읽거나 요구하지 않습니다. Vite 설정 근거는 [공식 환경변수 설정](https://vite.dev/config/shared-options#envdir)과 [파일 접근 제한](https://vite.dev/config/server-options#server-fs-allow)을 참고했습니다.

전체 스냅샷을 반환하는 HTTP 경로는 없습니다. 공개 스냅샷과 로그도 내부 상태를 직렬화한 뒤 필드를 삭제하는 방식이 아니라 허용된 필드만 새로 구성합니다. 서버 예외 메시지·환경변수는 HTTP 오류에 담지 않습니다.

| HTTP 경로 | 기능 |
|---|---|
| `GET /api/health` | M0·Mock·수동 시계 상태 |
| `GET /api/state` | 플레이어 공개 상태 |
| `GET /api/test/snapshot` | 공개 상태와 공개 로그 |
| `GET /api/test/logs` | 공개 로그 |
| `POST /api/test/reset` + `{}` | 고정 fixture로 초기화 |
| `POST /api/test/action` | `advance-clock`, `set-pause`, `mock-probe`만 허용 |

시계 전진은 요청당 1~60,000 정수 밀리초, Mock 입력은 공백이 아닌 최대 2,000자입니다. 알 수 없는 필드·명령, 잘못된 JSON과 비정상 요청은 거부합니다. 서버는 loopback에만 바인딩하고 Host·Origin을 검사합니다. 인증을 갖춘 배포 서비스가 아닌 본인 PC의 단일 사용자 시험 도구입니다.

## 이번 구현의 선택과 미구현 범위

- 시드는 난수 대신 버전이 붙은 고정 fixture(`m0-fixture-v1`)로 표현했습니다. 같은 행동 순서에서는 전체 내부 스냅샷·응답·이벤트 ID가 같습니다. 재시작 시 익명 시험 세션 ID도 같으며 분석용 사용자 식별자로 사용하지 않습니다.
- 지도·네 인물 이름과 문서 한 장은 실행 환경을 확인하기 위한 정적 자료입니다. 비공개 문서와 비공개 숫자는 누출 검사용 합성 자료이며 역사적 사실이 아닙니다.
- 시계는 **수동 시험용**입니다. 실제 시간 자동 진행, 입력 준비 후 25초 급보, 다음 사건까지 시간 보내기는 구현하지 않았습니다. 여러 보류 이유를 합성하는 기반은 있지만 작성·탭 전환 등에 대한 자동 UI 연결은 후속 단계입니다.
- M1의 `CommandDraft`·`Task` 생성·확인·중복 실행 방지·자원 소모·보고 연결은 없습니다. 실행할 수 없는 명령 시스템을 미리 만들지 않았습니다.
- 실제 Gemini, 자연어 해석, 복합 명령, 네 인물의 지식 변화·회의·접견, 시나리오 사건, 음성 입력은 없습니다.
- 상태는 메모리에만 유지됩니다. 저장 파일 불러오기, 여러 탭의 상태 동기화, 계정·DB·외부 배포는 지원하지 않습니다. 새로고침은 현재 서버 상태를 읽으며 서버 재시작은 초기화합니다.
- 작업 시작 시 이 폴더는 Git 저장소가 아니었습니다. `.gitignore`만 추가했으며 저장소 생성·커밋·push·배포는 하지 않았습니다.

처음 실행한 HTTP 시험은 샌드박스가 로컬 연결을 차단해 `EACCES`로 실패했습니다. 로컬 연결 권한을 부여한 재실행에서 통과했습니다. 의존성 설치 역시 제한 환경의 레지스트리 DNS 실패 후 권한을 부여해 완료했습니다. pnpm 저장소를 프로젝트 내부에 두고 파일 복사 방식을 사용해 전역 저장소 접근 문제를 피했습니다.

검증 중 없는 파일에 화면 HTML을 반환하던 Vite 기본 동작을 MPA 설정으로 바꾸어 404를 반환하게 했습니다. Host 차단 시험은 `fetch`의 헤더 보정 때문에 정확하지 않아 Node의 원시 HTTP 요청으로 수정했습니다. 최종 자동 시험에는 두 사항이 포함됩니다.

화면 증거: `artifacts/m0-browser.png`. 브라우저 도구의 연결·다운로드 확인에 지연이 있었으므로 도구 소요 시간을 앱 성능 측정값으로 사용하지 않습니다. 독립 Chrome·Edge에서의 교차 검증, 실제 키보드 IME 조합 이벤트, 서비스 중단 후 UI 복구는 별도 실기 시험이 남아 있습니다. 실제 모델 품질과 역사적 정확성은 이번 검증 결과에 포함되지 않습니다.

**M0 완료 기준 충족:** API 키 없이 실행, 동일 상태·행동의 재현, 브라우저에 내부 상태·키가 전달되지 않는 경계가 검증되었습니다. M1은 사용자 확인 이후에만 시작합니다.
